# Crate Structure

The workspace contains 6 crates:

| Crate | Purpose |
|-------|--------|
| mcs4-core | Gate, transistor, and solver primitives |
| mcs4-bus | MCS-4 bus protocol |
| mcs4-chips | 4004/4040 CPU, ROM, RAM implementations |
| mcs4-system | System integration and test fixtures |
| mcs4-gui | Terminal and GUI frontends |
| mcs4-fpga | FPGA synthesis stubs |
