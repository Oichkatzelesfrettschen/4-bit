# API Reference

Full API documentation is generated by rustdoc and available at [/api/](/api/).

## Key Types

- `ProcessParams` -- Semiconductor process parameters
- `PmosLevel1` -- Shichman-Hodges transistor model
- `CircuitGraph` -- Circuit representation for simulation
- `DcSolver` -- Newton-Raphson DC operating point solver
- `Simulator` -- Gate-level event-driven simulator
