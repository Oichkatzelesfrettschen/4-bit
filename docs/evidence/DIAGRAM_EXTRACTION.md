# Diagram + Transistor-Layer Extraction (Local Artifacts)

This document tracks *machine-readable* extractions from the bundled i400x analyzer bitmap assets
under `docs/emulators/`.

## Current Outputs

### Schematic OCR (circuit-level)

Generated by `./scripts/ocr_schematics.py --all --scale 4 --psm 11`:

- `docs/evidence/ocr_schematics/*_schematic.txt`: OCR text (best-effort; noisy).
- `docs/evidence/ocr_schematics/*_schematic.tsv`: per-word bounding boxes + confidence.

### Coordinate label OCR (signals.txt cross-check)

Generated by `./scripts/ocr_signal_labels.py --all --labels-only`:

- `docs/evidence/ocr_signal_labels/<chip>/*_signal_ocr_report.json`: per-point OCR results (includes `region_bbox`).
- `docs/evidence/ocr_signal_labels/metrics.md`: aggregated counts by chip.
- `docs/evidence/ocr_signal_labels/signals_txt_audit.json`: coordinate sanity-check output from `python3 scripts/verify_signals_txt.py --all`.

### Transistor candidates (poly/diffusion intersections)

Generated by `./scripts/extract_transistors.py --all`:

- `docs/evidence/transistors/*_poly_diffusion_transistors.json`: connected components over
  `poly ∩ diffusion` (candidate transistor gate intersections).
- `docs/evidence/transistors/metrics.md`: summary table from `./scripts/transistor_metrics.py`.
- `./scripts/validate_analyzer_claims.py`: tolerance check against analyzer-reported 4004 transistor counts.

## Important Limitations

- These are *not* full netlists. The i400x analyzer performs additional steps (metal/via tracing,
  contact handling, schematic parsing, reconciliation) that are not replicated here yet.
- `poly ∩ diffusion` overcounts/undercounts true transistors depending on how the bitmap encodes
  layers and how intersections are segmented; treat as “candidates” for follow-up.
- OCR is sensitive to pre-processing; for high-value labels, prefer cross-checking with the
  `i400x-signals.txt` coordinate maps and/or the original PDFs/GIF schematics.
- `i400x-signals.txt` entries are not always the exact text printed at the coordinate (some are net names);
  use `scripts/ocr_signal_labels.py` + `scripts/ocr_signal_aliases.json` for coordinate-based verification reports.
