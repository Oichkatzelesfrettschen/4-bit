# Power-rail evidence (working notes)

This file consolidates **primary-source** statements about MCS-4/MCS-40 power rails so that
layout anchor assignments for `VSS`/`VDD`/`VCC` can be audited.

Primary reference: `docs/evidence/PRIMARY_SOURCE_PINOUTS.md`.

## Pin-level rails (primary sources)

- **4001**: `VSS`=pin 5, `VDD`=pin 12
- **4002**: `VSS`=pin 5, `VDD`=pin 12
- **4003**: `VSS`=pin 5, `VDD`=pin 14
- **4004**: `VSS`=pin 5, `VCC`=pin 12

## Layout-side candidates (derived, not yet confirmed)

Candidates are generated by `scripts/suggest_power_rail_nodes_v0.py` and rendered by:

- `python -W error scripts/render_power_rail_candidates_v0.py --all`

Outputs per chip:

- `docs/evidence/power_rail_candidates_v0/<chip>/<chip>_power_rail_candidates_v0.json`
- `docs/evidence/power_rail_candidates_v0/<chip>/<chip>_power_rail_candidates_v0_overlay.png`
- `docs/evidence/power_rail_candidates_v0/<chip>/crops/`

Do not assign `layout_node` for `VSS`/`VDD`/`VCC` without evidence that ties a candidate node to the
**package pin** (e.g., via pad ordering + multiple already-confirmed signal pins, or corroborating
schematic annotations).
