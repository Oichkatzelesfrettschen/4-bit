# Netlists v1 Artifacts

This directory contains v1 layout-to-schematic bridge netlists used for
traceable anchor connectivity validation.

## Contents

- `{chip}_netlist_v1.json`: per-chip bridge netlists.
- `manifest.json`: inventory of generated netlist artifacts.
